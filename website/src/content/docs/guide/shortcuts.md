On macOS, `Ctrl` is `⌘`. The command palette (`Ctrl+K`) shows each
command's shortcut too.

## Windows and files

| Keys | What it does |
|---|---|
| `Ctrl+N` | New board |
| `Ctrl+O` | Open… |
| `Ctrl+S` | Save… (a new board) |
| `Ctrl+Shift+S` | Save a copy… |
| `Ctrl+W` | Close the window |
| `Ctrl+,` | Settings |
| `Ctrl+K` | Command palette |
| `Ctrl+I` | Inspector |
| `F6` / `Shift+F6` | Next / previous area |
| `Shift+F10`, Menu key | Context menu |

## Tools

| Keys | Tool |
|---|---|
| `V` | Select |
| `H` | Hand |
| `R` | Rectangle |
| `O` | Ellipse |
| `D` | Diamond |
| `Shift+T` | Triangle |
| `L` | Line |
| `T` | Text |
| `F` | Frame |

## Editing

| Keys | What it does |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z`, `Ctrl+Y` | Redo |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy / cut / paste |
| `Ctrl+D` | Duplicate |
| `Delete`, `Backspace` | Delete |
| `Ctrl+A` | Select all |
| `Ctrl+G` / `Ctrl+Shift+G` | Group / ungroup |
| `Ctrl+Shift+L` | Lock (unlock: right-click the board, **Unlock**) |
| `Ctrl+]` / `Ctrl+[` | Bring to front / send to back |
| `Ctrl+Alt+]` / `Ctrl+Alt+[` | Bring forward / send backward |
| `Ctrl+Shift+↑` / `Ctrl+Shift+↓` | Bring to front / send to back |
| `Ctrl+↑` / `Ctrl+↓` | Bring forward / send backward |
| Arrow keys | Nudge by 1 point (`Shift`: 10) |
| `Enter` | Edit the text |
| `Esc` | End editing, go back to the Select tool, leave a group, then clear the selection |
| `Tab` / `Shift+Tab` | The next / previous shape (after the last one, on to the next control) |

## Zoom

| Keys | What it does |
|---|---|
| `Ctrl+=` / `Ctrl+-` | Zoom in / out |
| `Ctrl+0` | Zoom to 100 % |
| `Ctrl+1` | Zoom to fit |
| `Ctrl+2` | Zoom to selection |
| `Ctrl` + scroll | Zoom around the pointer |
