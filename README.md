# Imaginarium

A cross-platform (Linux, Windows, macOS) office suite written in Rust that
puts **documents, presentations, page layouts, diagrams and drawings on
one whiteboard-like surface**. It has built-in generative AI (local or API
models) and end-to-end encrypted real-time collaboration through a
self-hostable server.

| Mode         | Replaces                   | Formats                        |
|--------------|----------------------------|--------------------------------|
| Board        | draw.io, Visio, whiteboard | `.imag`, SVG, PNG, PDF         |
| Document     | Word, Writer               | DOCX, ODT, PDF export          |
| Presentation | PowerPoint, Impress        | PPTX, ODP, PDF export          |
| Layout       | Publisher                  | `.imag`, PDF export            |
| Paint        | Paint (+ AI image tools)   | PNG, JPEG, WebP, AVIF          |
