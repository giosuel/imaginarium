# Architecture Decision Records

Each significant decision gets a short, numbered record. Records are never
edited after they are accepted. To change a decision, write a new ADR that
*supersedes* the old one.

Template: `0000-template.md`. Statuses: Proposed, Accepted, Superseded by NNNN.
